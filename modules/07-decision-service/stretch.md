# Module 7 — Decision service — stretch

Open-ended extensions. They are deliberately larger than one sitting and
have no reference solution.

1. Express the rules as data (YAML or a table) and reload them without a restart. Add a rule version to every decision.
2. Add a canary that sends 5% of traffic to a new rule set and compares block rates.
3. Build a replay tool that takes logged decisions and recomputes them with the recorded rule version.

Write down the trade-off you chose and the case where it would be the
wrong choice.
