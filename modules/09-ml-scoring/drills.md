# Module 9 — ML scoring — drills

Break-it exercises. There is no answer key on purpose: the point is to
see the failure, then explain which invariant broke.

1. Add a feature that counts attacks for the user, including the current event. Watch the offline metric jump and explain why it is a lie.
2. Replace the time split with a random split. Compare the holdout metric with the production shadow result.
3. Report accuracy only. Then report precision and recall at the rule's block rate and explain the difference.

Record what you observed, not just what you expected. A drill you
cannot reproduce is not finished.
