# Module 9 — ML scoring — stretch

Open-ended extensions. They are deliberately larger than one sitting and
have no reference solution.

1. Calibrate the model and show a reliability curve. Decide whether the raw score is usable as a probability.
2. Add drift detection on the top five features and alert when the population shifts.
3. Run a shadow rollout for a fixed window and write the promotion/rollback decision from the observed block rate and latency.

Write down the trade-off you chose and the case where it would be the
wrong choice.
