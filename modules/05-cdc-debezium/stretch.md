# Module 5 — CDC with Debezium — stretch

Open-ended extensions. They are deliberately larger than one sitting and
have no reference solution.

1. Add an outbox table and capture it instead of the user table. Explain why the outbox is transactionally consistent.
2. Handle a column rename end to end, including the target schema and the consumer code.
3. Capture two related tables and preserve referential order in the sink.

Write down the trade-off you chose and the case where it would be the
wrong choice.
