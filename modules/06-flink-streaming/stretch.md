# Module 6 — Flink stream processing — stretch

Open-ended extensions. They are deliberately larger than one sitting and
have no reference solution.

1. Implement a CEP pattern for three failures from three countries in ten minutes.
2. Use async I/O to enrich events from an external service with a bounded concurrency and a timeout.
3. Build an exactly-once Kafka sink with two-phase commit and document the remaining failure window.

Write down the trade-off you chose and the case where it would be the
wrong choice.
